# UI moderna, centrada y responsive (Tailwind)

Las guías nativas no son solo texto: la app tiene que sentirse moderna y agradable de recorrer en cualquier pantalla. Usamos Tailwind para layout centrado, responsive (móvil, tablet, desktop), animaciones sutiles y una UI coherente e innovadora. El contenido editorial no justifica una página plana o rota en móvil.
