# Hubs Classic: Era, Hardcore, SoD y MoP Classic

Las variantes Classic son expansiones de primer nivel: Classic Era, Hardcore, Season of Discovery y MoP Classic. No viven bajo un paraguas `classic`.

**Decisión:** el slug `classic` **redirige** a Classic Era (`/expansion/classic-era`, y el mismo recorte de path para `/profesion/...`). No es un alias silencioso: la URL canónica es `classic-era`.

El espejo `public/guides-mirror/classic/` queda asociado solo a **Classic Era**. Hardcore y Season of Discovery no heredan ese HTML. MoP Classic (`mop-classic`) es distinto de Mists of Pandaria retail (`mists-of-pandaria`).
