# Criterio de publicación de una guía nativa

Una guía nativa puede salir a producción con anatomía completa (intro, entrenador, lista de compras, rangos, cruces a otros tipos, TomTom, notas de raciales/skill) y tooltips en las entidades que el texto use. El pin/mapa in-game puede quedar en “próximamente” hasta elegir fuente (ADR implícito en Q23). Así Q23 no bloquea el publish.
