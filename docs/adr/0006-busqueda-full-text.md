# Búsqueda full-text: destino vs primer publish

El destino es búsqueda full-text de guías nativas con prioridad, y contenido provisional indexado pero marcado. Indexar el HTML espejado es un proyecto aparte. Si el piloto largo no cierra, el primer publish sale sin full-text (la nav de catálogo basta). No se bloquea Alquimia Midnight/TBC por el motor de search.
