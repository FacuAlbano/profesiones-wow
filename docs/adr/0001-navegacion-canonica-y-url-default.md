# Navegación canónica y URL default = Subida de nivel

El producto cubre muchas expansiones y tipos de guía. Las URLs canónicas siguen Expansión → Profesión → Tipo de guía; la página `/expansion/:exp/profesion/:prof` *es* la Subida de nivel. Los demás tipos viven en subrutas. Así el embudo principal (1→cap) no exige un segmento extra y no multiplicamos landings vacías por profesión.
